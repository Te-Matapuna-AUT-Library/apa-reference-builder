The four elements of every APA reference

Every APA reference is built from the same four parts. Learn to spot them in your source and the tool will format them for you. Start by choosing what kind of source you have, because a book, a journal article, and a web page each need slightly different details, and the tool shows you which.

1. Author

Who wrote it?

A person or an organisation. The tool inverts names for you, so Ranginui Walker becomes Walker, R.

2. Year

When was it published?

Usually a single year, like (2004). Use n.d. when there is no date.

3. Title

What is it called?

Set in sentence case. Only the first word and any names take a capital.

4. Source

Where is it found?

The publisher, journal, DOI, or URL that lets a reader locate it.
